개인정보처리방침

1. 운영 목적과 적용 범위

AutoRils 운영자는 권한을 부여받은 Instagram 계정과 Facebook 페이지의 창작 콘텐츠 제작, 게시, 수정·삭제 및 게시 결과 확인에 필요한 정보를 처리합니다. 이 방침은 AutoRils가 처리하는 정보에 적용되며 외부 플랫폼 자체의 정보 처리에는 해당 플랫폼의 정책이 적용됩니다.

2. 처리하는 정보

  • 계정 연동 정보: 승인된 계정·페이지의 식별자와 이름, 연결된 Instagram 계정, 허용된 권한 및 관리 작업 정보.
  • 인증 정보: Meta API 액세스 토큰과 연동 서비스의 API 인증 정보.
  • 콘텐츠 및 운영 기록: 대본, 이미지, 음성, 영상, 게시 문구, 게시물·업로드 식별자, 게시 링크·시각, 처리 상태, 오류 및 검수 기록.
  • 문의 정보: 이메일 문의나 삭제 요청 시 제공하는 이메일 주소, 계정 식별 정보, 요청 내용.

현재 제작·게시 기능에서는 일반 시청자의 비밀번호, 결제 정보, 연락처 목록, 개인 메시지 및 댓글 본문을 수집하는 기능을 운영하지 않습니다. 앱에 부여된 권한의 범위와 실제 사용하는 데이터 범위는 다를 수 있습니다.

3. 이용 목적

관리 권한 확인, 콘텐츠 생성·게시, 게시 상태 검증, 중복 게시 방지, 오류 해결 및 삭제 요청 처리에 이용합니다. 개인정보를 판매하거나 광고 타기팅용으로 제공하지 않습니다.

4. 저장 및 보관

인증 정보는 운영 환경의 비공개 설정에 저장하며 콘텐츠와 게시·검수 기록은 운영 작업 공간에 보관합니다. 계정 연동 정보는 해당 연동을 유지하는 동안, 콘텐츠와 운영 기록은 채널 운영·수정·장애 대응에 필요한 동안 보관합니다. 자동 일괄 삭제 주기는 현재 설정되어 있지 않습니다.

연동 종료 또는 삭제 요청 시 불필요한 정보를 삭제하고 관리 가능한 사본·백업에도 반영합니다. 법령상 보관 의무나 분쟁 대응 등의 이유로 일부 보관이 필요한 경우 범위와 사유를 요청자에게 안내합니다. 외부 플랫폼의 공개 게시물 삭제는 별도 절차가 필요할 수 있습니다.

5. 외부 서비스

  • Meta(Facebook·Instagram): 승인된 계정 확인, 영상·게시 문구 업로드, 게시 상태 확인과 콘텐츠 관리에 공식 API를 이용합니다.
  • OpenAI/Codex: 창작 대본·프롬프트와 필요한 참조 자료를 바탕으로 제작 작업과 이미지 생성을 수행합니다.
  • ElevenLabs: 대사와 음성 설정을 전달해 음성을 생성하고, 생성된 음성을 전달해 전사 검수를 수행합니다. Meta 액세스 토큰을 음성 생성 입력으로 보내지 않습니다.
  • GitHub Pages: 이 공개 안내 페이지를 호스팅합니다. GitHub가 IP 주소 등 접속 정보를 자체 정책에 따라 처리할 수 있습니다.

외부 서비스는 국외 서버를 사용할 수 있으며 각 서비스의 개인정보처리방침이 적용됩니다. 안내 사이트 자체에는 회원가입, 분석 추적 스크립트, 광고 및 입력 폼을 두지 않습니다.

6. 정보 보호

API 키와 액세스 토큰은 공개 저장소와 안내 페이지에 포함하지 않습니다. 운영 파일 접근을 관리하고 API 통신에 HTTPS를 사용합니다. 불필요하거나 노출된 인증 정보는 폐기·재발급하여 접근을 차단합니다.
